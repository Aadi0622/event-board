# Campus Event Board

Campus Event Board is a responsive web project created for IIIT Vadodara.

## Features

- Upcoming campus events
- Event registration form
- Event categories
- FAQ section
- Contact information
- Responsive layout
- CSS Grid
- Responsive navigation

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Responsive Web Design

## Project Files

- `index.html` - Main webpage
- `style.css` - Styling and responsive design
- `Asset/` - Project images and assets
